# Nomi

Nomi is a small Flask web app for uploading comics, manga, and books into a
self-hosted [Kavita](https://www.kavitareader.com/) library.

The home page is a launcher: one button opens Nomi's own uploader, and the
rest are links to your other self-hosted apps (Kavita, Immich, anything else
you configure), which open in a new tab. Files are stored in the layout
Kavita expects:

```
<Library Root>/
└── <Series Name>/
    ├── Series Name v01.cbz
    └── Series Name v02.cbz
```

The app creates the series folder if it doesn't exist, or adds files to it if
it does. Existing series are suggested as you type so you don't create
duplicate folders. The UI is mobile-friendly, so you can upload from a phone.

Uploaded files are renamed to Kavita's naming convention. The volume, chapter,
or issue number is detected in the original filename and the file is renamed
to `<Series> v01.cbz`, `<Series> Ch. 003.cbz`, or `<Series> 001.cbz`. When you
create a new series you can optionally give its first release year, which is
appended as `<Series> 001 (2020).cbz`. A file with no detectable number is
treated as a one-shot and named after the series (original name is kept if
several such files are uploaded together, to avoid collisions).

The app also includes a media content generator: enter a prompt and an
image is generated by your ComfyUI server, with a download button. You can
also upload an image and have a vision model write the prompt for you.

## Setup

```bash
cd nomi-app
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # then edit .env with your library paths
python app.py
```

Open http://localhost:5000 in your browser.

## Configuration (.env)

| Variable | Description |
| --- | --- |
| `LIBRARY_<NAME>` | One per library: root path of that Kavita library (e.g. `LIBRARY_MANGA=/data/manga`, `LIBRARY_BOOKS=/data/books`). Add as many as you need. |
| `APP_<NAME>` | One per external app: its URL (e.g. `APP_KAVITA=http://nas:5001`, `APP_IMMICH=http://nas:2283`). Each becomes a button on the home page that opens in a new tab. A bare host gets `http://`; non-http(s) values are ignored. |
| `HOST` / `PORT` | Where the app listens (defaults: `0.0.0.0` / `5000`). |
| `SECRET_KEY` | Flask session secret — set to any random string. |
| `MAX_UPLOAD_MB` | Max upload size per request in MB (default `1024`). |
| `ALLOWED_EXTENSIONS` | Comma-separated list of accepted extensions. |
| `KAVITA_URL` / `KAVITA_API_KEY` | Optional. If both are set, the app triggers a Kavita library scan after each upload (API key: Kavita → Settings → Account → API Key). |
| `COMFYUI_URL` | Optional. Base URL of a running ComfyUI server (e.g. `http://nas:8188`). Enables the media content generator on the home page. |
| `COMFYUI_WORKFLOW` | Optional. Path to a ComfyUI API workflow JSON (defaults to the bundled `workflows/ZImageTurbo-Workflow-API.json`). |
| `COMFYUI_OUTPUT_DIR` | Optional. Local folder where ComfyUI saves generated images; used by the download button (default `~/ComfyUI/output`). |
| `NIM_VISION_MODEL` | Optional. Vision model to use for generating prompts from images (default `meta/llama-3.2-11b-vision-instruct`). |
| `NVIDIA_API_KEY` | Optional. NVIDIA API key for accessing NIM models. Required for "Generate prompt from image". |

Without the Kavita API settings, files are still stored correctly and Kavita
will pick them up on its next scheduled scan (or a manual scan).

## Notes

- Series names are sanitized (path separators and invalid filesystem
  characters removed) and path traversal is blocked.
- Files that already exist in the target folder are skipped, never overwritten.
- App links are used as given, so point them at addresses reachable from the
  device you browse from — `localhost` will not resolve from your phone.
- The app has no authentication — keep it on your LAN or put it behind a
  reverse proxy with auth if you expose it.
